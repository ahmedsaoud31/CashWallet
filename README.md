# محفظة الكاش (Cash Wallet) — الإصدار v1.0.1-beta

**إصدار التحسينات الشاملة v1.0.1-beta** (`2026-11-06`)

يحتوي هذا المجلد على ملفات الإصدار الجاهزة للتحميل والتثبيت:

## محتويات الإصدار

| الملف | الوصف | النظام |
| :--- | :--- | :--- |
| `CashWallet_Setup_v1.0.1-beta.exe` | برنامج تثبيت تطبيق سطح المكتب | Windows (64-bit) |
| `CashWallet.apk` | تطبيق الهاتف المرافق (SMS Companion) | Android |

---

## ما الجديد في الإصدار `v1.0.1-beta`

- تحديث نظام قواعد البيانات
- تحديث أيقونة التطبيق
- معالجة بعض مشاكل العرض
- إضافة عرض الجداول لصفحة إدارة المحافظ
- إضافة ترقيم الصفحات لكل من الصفحة الرئيسية وصفحة سجل الحركات وصفحة إدارة المحافظ
- إضافة إمكانية تفعيل/إلغاء تفعيل المحافظ
- إضافة نظام التحديث التلقائي الصامت للبرنامج بنقرة زر واحدة
- أخذ نسخة احتياطية محلية فورية لحماية البيانات قبل أي ترقية

---

## طريقة التثبيت

### 1. نسخة سطح المكتب (Windows)
1. قم بتحميل الملف `CashWallet_Setup_v1.0.1-beta.exe`.
2. شغّل ملف التثبيت واتبع خطوات المعالج لإكمال التثبيت.

### 2. تطبيق الهاتف المرافق (Android)
1. قم بتحميل الملف `CashWallet.apk` على هاتفك.
2. افتح الملف ووافق على التثبيت من مصادر غير معروفة إذا طُلب منك ذلك.
